# 라이트 히어로 = 금환일식(Annular Eclipse) 진행형

## 컨셉 (조사 기반)
스크롤 = 달이 차오르는 상태. rest에서는 백열하는 태양 림이 크림 하늘을 비추고, 스크롤에 따라 **에스프레소색 달 원반이 아래에서 떠올라 태양을 물어 덮고**, 완식(uLight=1)에서 **얇은 백열 금환(ring of fire)** 이 남는다. 지금의 브론즈 채움(월식 느낌)은 완전히 폐기.

실제 금환일식 사진의 3요소를 그대로 가져온다: ①무광 달 실루엣 + 백열 광구 ②베일리 구슬/다이아몬드 링 순간 ③다중 스케일 블룸(하드 외곽선 제거 — 유저가 지적한 "끊겨 보이는 외곽선"의 직접 수정).

## 파레트 (명암비율 수정 — 이전 "색 조합 미고려" 거부 반영)
- 하늘: 크림 `vec3(0.945)` → 금환에 가까워질수록 원반 주변 국소 가라앉음 + 전체 살짝 딥크림(완식 하늘도 밝게 유지 — 조사 결과 금환일식은 하늘이 밝음)
- 태양 광구: 백열 웜화이트 `vec3(1.0, 0.96, 0.87)` — 질감 없음(필터 없는 백열 사진처럼), 평면 그래픽처럼 안 보이게 블룸이 생명
- 달 실루엣: 딥 에스프레소 `vec3(0.12, 0.09, 0.075)` — 회색 행성 아님, 구리빛 월식 아님
- 금환: 코어 `vec3(1.0, 0.97, 0.90)` → 바깥으로 골드 `vec3(1.0, 0.85, 0.60)` 지수 감쇠

## 셰이더 구현 (sunShader.ts 단일 파일)
1. **다크 경로 복원**: 지난 라운드의 uTheme 팔레트 mix 4곳(dark/core/mid/edge)을 다크 상수로 되돌림. 종단선도 `* 0.30` 복원. 다크 모드는 최종적으로 픽셀 불변.
2. **라이트 일식 블록 추가** (비네트 직전, `col = mix(col, eclipse, uTheme)` 전면 교체 구조):
   - 기하: 달 = 같은 타원(stretch 공유), 반경 `s·R` (s≈0.965 → 금환 두께 ~23px@720p). 화면 법선 거리로 타원 좌우에서도 림 빛 두께 일정(fwidth AA — 기존 검증된 기법)
   - 궤도: `mOff = mix(R(1-s) − limbAboveSeam, 0, uLight)` — 달이 화면 하단에서 떠올라 중심에 안착. 계산상 달 원반은 항상 태양 원반 내부라 하늘에 나오는 검은 원반(행성처럼 보이는 실패)이 없음. 부분식 중반 = 밝은 원반에 어두운 물림
   - 태양 림 소프트 마감: 테이트 헤일로 `exp(-e/0.008)` + 미드 블룸 `exp(-e/0.035)` + 와이드 글로우 `exp(-e/0.12)` 3단 지수 감쇠 — 하드 라인 전무
   - 금환: 태양 마스크 − 달 마스크, 코어 백열 + 달 쪽 내부 블리드 + 바깥 블룸. 저주파 fbm으로 천천히 숨쉬기(광선·반짝임 장식 없음 — restraint)
   - 다이아몬드 링/베일리 구슬: 부분식 후반(uLight≈0.75~0.98) 달 림과 태양 림 간격 최소부에 국소 백광 — 캡처 보며 강도 튜닝, 어긋나면 과감히 제거
3. **불변 유지**: uLight 매핑(LIGHT_START 0.05→END 0.8), uNight 밤 페이드, 헤더, 카피 페이드 모두 무수정. SunCanvas.tsx 수정 없음.
