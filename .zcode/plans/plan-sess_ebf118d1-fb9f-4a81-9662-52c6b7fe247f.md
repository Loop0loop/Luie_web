# 히어로 → 섹션 전환 개선 + 섹션 파일 분리

## 1. 빛 채움을 행성 안으로 제한 (sunShader.ts)

**원인**: 종단 금빛 라인(terminator)이 `dist` 마스킹 없이 화면 전체 폭에 그려지고, `yLine` 종점(-0.08)이 림 상단(-0.18)보다 위여서 라인이 우주 공간을 가로지름.

**수정** (직선 → 행성 동심원 곡선으로 바꾸면서 마스킹까지 해결):
- 종단선을 반경 기반으로 변경: `R_line = yLine + 1.66` (행성 중심으로부터의 반경), 밴드 = `exp(-abs(dist - R_line) * 22.0)` → 빛 경계가 림과 동심원인 호를 그리며 상승
- `lit` 채움 마스크도 같은 반경 기준으로 변경: `lit = 1 - smoothstep(R_line - 0.05, R_line + 0.05, dist)`
- 밴드를 원반 내부로만 클리핑: 기존 `outside`의 역수 `(1.0 - outside)`를 곱해 림 밖으로 한 픽셀도 나가지 않음
- `yLine` 종점은 -0.08 유지 (R_line=1.58 > R=1.48 → 림까지 완전히 채워짐은 그대로, 밴드만 원반에 클리핑되어 소멸)

## 2. 다음 섹션 상단에 반원(돔) 배치 — 사용자 아이디어 채택

**채택 이유**: 히어로 행성이 위로 흘러가 나가는 대신, 아래에서 같은 곡률의 어두운 돔이 이어받으면 "한 행성을 지나 스크롤한다"는 연속성이 생김. 두 번째 셰이더 캔버스는 비용 대비 과하므로 순수 CSS로 충분.

- `src/components/sections/FeaturesSection.tsx` 상단에 원형 div 하나 추가
  - 지름 `296vh` (셰이더 R=1.48의 지름 2.96×뷰포트높이와 정확히 일치 → 곡률 매칭), 수평 중앙 정렬
  - 색: 셰이더 다크 실루엣 톤 `rgb(19,7,5)` 부근 + 상단 림에 은은한 warm 하이라이트 (inset shadow / radial gradient) — 시임 직전 행성 가장자리 톤(이미 어두움)과 매칭
  - 섹션 상단보다 살짝 위로 돌출(negative top)해 히어로 캔버스 하단의 flat 시임 밴드를 삼켜서 이음새 제거
  - 돔 본체(296vh)가 아래 섹션들까지 흘러내리지 않도록 래퍼에 `clip-path: inset(위로는 여유, 아래로는 잘림)` 처리
  - 돔은 피처 섹션의 배경 "지평선"으로 잔존 (콘텐츠가 그 위에 앉는 구조), reduced-motion 영향 없음
- z-order: 섹션이 DOM 뒤에 오므로 전환 시 돔이 캔버스 하단 위에 자연히 덮임. 쌓임 맥락 문제 시 z-index 명시

## 3. App.tsx 섹션 파일 분리 (SRP)

`src/components/sections/` 신설, 섹션당 파일 하나 (자신의 id·번호·타이틀·힌트를 스스로 소유, 당분간 `SectionStub` 렌더):
- `FeaturesSection.tsx` (02 기능 — 돔 포함)
- `LayoutsSection.tsx` (03 레이아웃)
- `CanvasGraphSection.tsx` (04 캔버스 & 그래프)
- `MoreSection.tsx` (05 기타 기능)
- `FaqSection.tsx` (06 Q&A · 커뮤니티)

`App.tsx`는 `SECTIONS` 배열을 지우고 다섯 섹션을 순서대로 조립만. id 유지로 헤더 앵커(#features 등) 호환. 섹션이 실제 콘텐츠가 될 때 각 파일이 자리를 대체.
